# 24. 放量弹性

定义：

```text
Scale Elasticity
=
销量增长率 ÷ 广告费增长率
```

例如：

```text
预算 +15%
销量 +15%

Elasticity = 1.0
```

---

# 25. 放量弹性评价标准

| Elasticity | 判断 |
|---:|---|
| ≥0.8 | **非常好，继续放量** |
| 0.5～0.8 | 可以继续 |
| 0.3～0.5 | 保持观察 |
| <0.3 | 停止增加 |
| ≤0 | **回退** |
