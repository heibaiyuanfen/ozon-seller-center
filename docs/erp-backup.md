# 产品库备份（本机调试）

> 当前已按用户要求停用：软件不再显示产品库入口，也不在上架后调用备份、台账上传或重试。以下为历史实现说明；已有本地备份及 ERP 数据保留，配置 enabled=true 也不会自动恢复上传。需重启源码版以加载停用变更。

## 上传现有台账

在连接窗口点击“上传现有产品台账（空字段留空）”，选择 Excel 文件并确认。当前统一使用 ERP 1.1.0 /follow-backups/validate 和 /import 增量接口，不再调用普通产品创建接口。

名称、货号、成本、类目、图片等业务字段均可留空，不补零、不编造；仅允许明确的 Ozon 跟卖台账。界面支持选中行、筛选结果和全部台账，先预览后确认上传。为缺少货号的行保留稳定身份，征得确认后在 Excel 新增隐藏记录 ID 列，不修改业务字段。请关闭 Excel 后操作。

包装尺寸/重量在单位可确认时填写 variants.package，保守标注 unknown；历史单位未知时留空并保留原始台账行。关联原提交时须精确匹配店铺、货号和导入任务 ID，不能使用被另一家同货号覆盖的提交文件。新台账写入前按原提交单位换算为 mm/g。

来源记录的 extensions.ledger_row 保存原行及利润、佣金、运费、贴单费；没有店铺稳定 ID 时不伪造店铺记录，原行保存在产品 extensions。已有任务产品组可恢复 A/B 产品与规格身份；1688 批量变体携带明确的产品/规格 ID。只有弱标题或链接相同时生成疑似重复报告，不自动合并。新批次复用精确店铺货号关联或明确产品规格 ID，不能仅靠来源链接识别。

台账和自动备份共用 erp-backup/identity.json 的 namespace 与身份映射，失败原样重试，字段差异明确显示。旧 erp-ledger/state.json 中已用普通草稿接口创建的产品没有增量来源绑定：拦截并报告其旧产品 ID，需 ERP 端迁移，不删除、不重新建品、不覆盖人工数据。

入口：服务配置 → 产品库连接 / 重试备份。

1. 启动已升级接口的本机 ERP，默认根地址 http://127.0.0.1:8788。
2. 无图台账无需图片白名单；补图时在 ERP 配置准确的 OSS 公共图片主机白名单。
3. 在连接窗口填写本地访问密钥，或多人账号和密码。凭据仅本次进程及其子进程有效，不写入配置导出、备份 JSON 或安装包。重启软件需重新填写。
4. 点击测试连接，确认鉴权和 schema 接口可用。
5. 勾选自动备份并确认。默认关闭，不向未确认的地址发送商品资料。

执行顺序：当前货号明确 imported 成功 → 库存 → Excel 台账 → 固定提交 JSON → 保存备份源资料 → validate → import → 保存 ERP product_id 和回执。

备份失败不会撤销上架，不会重跑创建商品或库存。可在连接窗口独立重试；超时、5xx、写锁冲突有限退避，同一任务重发相同 JSON 字节和 export_id。401、403、422、版本冲突不盲目重试。校验预览及导入回执保存在本机 erp-backup/，源资料在 sources/，勿删除待上传文件。

有可靠关联的 A/B 任务共用产品/规格身份，分别保留店铺记录及不同创意快照。1.1 不发送客户端 revision，ERP 自动生成版本；已有非空值不覆盖，差异显示待确认。待上传 JSON 内容寻址缓存，保存 export_id、预览、回执及 ERP product_id；切换地址不会跨库重试。旧 1.0 待上传文件仍可原样重传。

迁移电脑时须完整保留程序数据中的 erp-backup/、erp-ledger/、auto_jobs.json 和台账文件，尤其 namespace、身份映射及待上传原始 JSON。不要只复制 Excel 后丢失身份数据。

包装数据保守标记 unknown，不将估算值冒充实测。ERP 当前只保存公开链接，不下载图片；软件明确提示草稿资料、图片未验证，不显示为新店铺发布成功。原 OSS 链接如果会被覆盖或删除，备份无法保证历史图片字节不变。

本机联调测试使用 ERP 的 FastAPI 路由、真实 schema、服务层和临时 SQLite 数据库，不读取本机正式访问密钥，不修改正式数据库，不调用 Ozon、AI 或 OSS。
