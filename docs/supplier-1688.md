# 1688 图片与变体

入口为第 9 页“1688 图片与变体”。输入标准商品详情链接，点击“采集图片”。
浏览器要求登录或验证时由用户完成。程序收集页面加载出的商品图片候选，
最多下载 80 张，通过浏览器登录会话下载，不使用模拟商品或模拟图片。
实际可读取的图片取决于平台页面和账号可见范围。

候选素材按识别结果分为候选、规格、详情，也可补充本地图片。分组仅用于筛选，
不代表已经准确识别供应商 SKU。用户手动创建或复制产品变体，为每个变体
选择最多 15 张上传图片。默认不自动选择图片。

左栏维护变体名称、独立货号、合并型号、成本和包装参数。
中栏可预览并多选素材，加入当前变体。右栏维护实际上传列表，支持设主图、
上移、下移、移除、旋转和坐标裁剪。编辑结果另存为副本，不修改下载原图。
不同变体共享原始素材，但图片选择及编辑列表相互独立。

“载入自动工作台”将当前变体图片及采购链接送入本地新品流程。
随后核对店铺、类目、核价、包装参数和库存，再加入上架队列。
要直接使用处理好的图片而不添加水印，在服务配置选择“原图直接上架”。
也可点击“全部变体批量上架”，一次提交当前产品所有未清除记录的变体。
使用自动工作台当前选择的店铺、类目、佣金、目标 ROI、贴标费、广告、货损和库存；
各变体分别使用自己的货号、采购成本、重量、尺寸和图片，分别核价。
校验整批资料并统一确认后才加入队列，并发数至少为 3。
同一变体可展开到多个店铺；已有同店铺同货号记录时会阻止重复加入。

“清除当前产品记录”和变体“清除记录”仅隐藏记录，可使用对应恢复按钮重新显示。
图片、编辑副本、采购资料和变体数据全部保留。
自动工作台的“清除已结束任务”同样只隐藏结束记录；断点及业务数据保留，
点击“恢复已清除记录”恢复显示，不会重新启动或提交这些任务。

所有商品和变体保存在程序数据目录的 `supplier-1688/workspace.json`，
素材和编辑副本也在该目录内。复制变体会分配不同货号。
该目录已加入 Git 忽略规则。不要手动删除未完成变体正在使用的图片。
