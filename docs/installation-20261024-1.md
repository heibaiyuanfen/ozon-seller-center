## 更新已安装的软件

1. 等待运行中的上架任务结束，退出软件。
2. 备份原安装目录中的“程序数据”文件夹。
3. 运行 2026.10.24.1 安装包，选择原来的安装目录，直接覆盖安装。
4. 从原快捷方式重新打开软件。

安装沿用原 AppId，更新程序文件；已存在的服务配置、台账、数据库和缓存不会被安装包覆盖。
任务、图片和工作台数据不会在更新时删除。无需先卸载旧版。
如果使用源码启动，更新源码后需退出旧进程，再运行启动脚本。
已安装的 EXE 不会因为拉取 GitHub 源码而自动更新。

## 新电脑

支持 Windows 10/11 64 位，自带 Python、Tcl/Tk、Playwright、Edge 和图像处理依赖。
采集优先使用内置浏览器，无需预装 Chrome 或 Python。
首次访问平台可能需要登录或验证；电脑仍需正常访问平台、图片 CDN、AI 和 OSS 服务。

本安装包包含当前服务配置和密钥，只能私下传递。
产品库连接配置在新安装时初始化，更新时保留用户已有配置。
