# 2026-10-24 安装版

本次以 Git 提交 e0d16c6 为基础，包含本次浏览器与打包兼容修复。

## 新电脑要求

- Windows 10/11，64 位；安装到当前用户目录，无需管理员权限。
- 程序自带 Python、Tcl/Tk、Playwright 驱动、图像处理和 Excel 依赖。
- 程序自带 Edge 浏览器运行文件，采集优先使用内置浏览器；无需另装 Chrome、Python 或浏览器驱动。
- 需要能够访问商品页面、图片 CDN、平台 API、AI 和 OSS 服务的网络。
- 首次访问平台时，可能需要在采集窗口登录或完成平台验证。浏览器登录状态不从旧电脑复制。
- 使用 Codex 桌面交接生图时，仍需要单独安装并登录 Codex；直接 AI API 模式使用服务配置中的账号。

## 服务配置

安装包包含本机 config.json 中保存的服务配置和平台账号，以及现有台账和基础缓存。
已有安装的数据文件使用“存在则保留”的方式安装，不覆盖新电脑已有的配置。
安装包含密钥，只能私下传递，不能作为公开 GitHub 附件发布。
旧任务队列和工作台中的本机绝对图片路径不随安装初始化，以免在新电脑误重试旧任务。

## 验证边界

构建自检覆盖界面、Excel、核价、WB、1688 工作区，以及内置浏览器的页面识图、下载和图片解码。
离线自检不等同于目标电脑的真实网络测试，也不会实际创建平台商品、扣费生图或上传 OSS。
采集窗口不能关闭；网络、平台登录验证、服务账号权限、额度与安全软件限制仍需在目标电脑确认。
