# 2026.10.24.3 覆盖更新安装版

包含 DATA_MODEL 1.2.0 的 wff 产品库上传适配、类目合并型号兼容修复、台账图片链接与历史补图功能。
上传前核对服务器 wff/ready 能力，保留原来源身份、请求及回执，不批量重建历史商品。
来源链接可留空或填中文测试占位；上传时仅传有效公开链接。

## 覆盖更新

1. 等待正在运行的任务结束，退出旧版软件。
2. 备份旧安装目录中的“程序数据”文件夹。
3. 直接运行本安装包；使用相同 Windows 用户，安装程序会优先采用已有安装目录。
4. 若无法自动识别，请手动选择原来的软件安装目录，再继续安装。
5. 安装完成后通过原快捷方式重新启动。

无需先卸载。更新只替换程序文件；已有服务配置、产品库连接配置、任务队列、台账、数据库、图片和上传回执保留。
数据文件仅在目标不存在时初始化。没有旧安装时按全新安装处理。
若使用环境变量 OZON_RFBS_DATA_DIR 指向其他数据目录，保持原来的启动方式和环境变量设置。
通过 ZIP 解压或源码启动的目录没有安装登记，需手动指定正确安装目录或继续使用源码启动方式。

支持 Windows 10/11 64 位，自带 Python、Tcl/Tk、Playwright 和 Edge。
网络、账号额度及平台登录验证仍需可用。
产品库 ready 状态由服务器设置，不表示平台审核通过，也不触发额外上架任务。

安装包包含当前服务配置和 API 密钥，只能私下传递。
