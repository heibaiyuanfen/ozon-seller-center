# 2026.10.24.2 更新说明

## 类目兼容修复

“型号名称（针对合并为一张商品卡片）”不再作为所有 Ozon 类目的固定前置条件。
兼容带括号说明的俄文型号名称。没有返回该属性时继续读取其他属性并按独立商品提交，型号保留在台账。
类目真正必填的属性仍需填写；不提供合并型号的类目不能据此保证合并为同一商品卡片。

修复旧失败任务：更新后选择“修复选中任务”，加载/刷新当前类目属性，再保存修复并继续运行。
已经完成的上架任务无需重新上架。

## 台账图片链接

Ozon 成功上架时，将实际提交的公开图片地址写入台账新列：主图链接、附图链接、全部图片链接JSON。
主图排在第一位，附图保留提交顺序，重复地址会去重。
图片列按店铺和货号对应商品，后续仅更新其他字段时保留已有图片链接。
从台账向产品库补传时，会读取这些图片链接；无图片的旧台账仍可上传基础资料。
这些列不保存本机图片文件路径，也不会再次生成图片或上传到 OSS。

历史补图入口：服务配置 → 产品库连接 → 从台账补传基础资料 → 选择台账 → 从成功提交记录补齐台账图片链接。
只使用本机“输出”目录中可以核对货号、店铺、导入任务和成功状态的提交记录。
补图前自动备份到台账所在目录下的“台账备份”文件夹，只填补缺失图片，不覆盖其他字段。
缺少原成功提交记录，或存在跨店铺歧义时，保持原样。
已经入库的资料仍遵守产品库接口的冲突保护，不会更换来源身份重复建品或强制覆盖。

## 安装更新

等待任务结束，退出软件，备份“程序数据”文件夹，然后运行安装包选择原目录直接覆盖安装。
无需卸载旧版，已有配置、任务、台账和图片会保留。
拉取 GitHub 源码不会自动更新已经安装的 EXE。

支持 Windows 10/11 64 位，自带 Python、Tcl/Tk、Playwright 和 Edge。
首次平台访问仍可能需要登录或人工验证，并需要正常的网络和有效服务账号。
安装包包含服务配置和 API 密钥，只能私下传递。
