# 脚本索引

> 按实际编写/运行顺序排列。`batch_run.py` 是最终交付脚本。

| 脚本 | 作用 | 大小 |
|---|---|---|
| `batch_run.py` | 最终批量脚本：增量抓货源 + 生成全表 200 行交付 xlsx | 13.8 KB |
| `browser_probe.py` | 用系统 Chrome 渲染 1688 搜索页（发现直接跳淘宝登录页） | 1.9 KB |
| `build_full_sample.py` | 用真实图搜结果回填 5 条完整货源样本 | 11.9 KB |
| `build_sample.py` | 生成 5 条格式样本：OZON 高清图 + 检索词 + 搜索直达 + 列骨架 | 6.7 KB |
| `image_search.py` | 上传 OZON 图片并点击「搜索图片」，验证同款结果 | 3.9 KB |
| `inspect_xlsx.py` | 读取源表结构、表头、行数与链接列样例 | 0.8 KB |
| `login_1688.py` | 开有头 Chrome 等用户扫码登录 1688，保存 storage_state 会话 | 3.4 KB |
| `pass_captcha.py` | 开有头窗口等待人工过滑块（5 分钟未通过） | 2.0 KB |
| `probe_1688.py` | 探测 1688 搜索页静态 HTML 能否解析出商品（结论：JS 空壳） | 2.0 KB |
| `probe_air_direct.py` | 关键突破：直连 air.1688.com 图搜结果页不受风控 | 2.4 KB |
| `probe_captcha.py` | 探测并尝试自动通过阿里滑块验证（失败） | 3.1 KB |
| `probe_cards.py` | 解析图搜结果页商品卡片的 DOM 结构与字段位置 | 3.4 KB |
| `probe_logged.py` | 登录后校准关键词、定位「以图搜款」上传入口 | 3.5 KB |
| `restore_sample.py` | 重建被误覆盖的 3 条真实货源数据样本 | 6.3 KB |
| `test_air_reupload.py` | 验证在结果页内换图可刷新 imageId 与同款结果 | 3.1 KB |
| `test_network.py` | 实测 OZON 图片 CDN / 商品页与 1688 连通性 | 2.6 KB |
